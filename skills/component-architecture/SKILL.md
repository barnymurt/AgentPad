# Component Architecture

Design frontend component structure for scale and reusability. This skill creates maintainable component systems.

## Core Workflow

### Step 1: Identify Components
- Break UI into pieces
- Identify reusability
- Define boundaries

### Step 2: Define Hierarchy
- Parent/child relationships
- Composition patterns
- Data flow

### Step 3: Design Props
- API surface
- Types
- Defaults

### Step 4: Document Patterns
- Usage examples
- Do's and don'ts

## Output Format

- Component hierarchy
- Prop definitions
- Pattern documentation

## Quality Criteria

- [ ] Components are reusable
- [ ] Hierarchy is clear
- [ ] Props are well-designed

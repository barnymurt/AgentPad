# Accessibility Review

Ensure accessibility compliance. This skill makes your app usable by everyone.

## Core Workflow

### Step 1: Audit
- Automated tests
- Manual review
- Screen reader testing

### Step 2: Identify Issues
- Contrast
- Keyboard navigation
- Screen readers

### Step 3: Remediate
- Fix code
- Add ARIA
- Improve structure

### Step 4: Verify
- Re-test
- Document
- Train team

## Output Format

- Audit report
- Issue list
- Remediation plan

## Quality Criteria

- [ ] WCAG compliant
- [ ] Keyboard navigable
- [ ] Screen reader friendly

# Test Strategy

Define testing strategy for your project. This skill creates your test plan.

## Core Workflow

### Step 1: Assess Risk
- Project complexity
- User impact
- Regulatory needs

### Step 2: Define Pyramid
- Unit tests
- Integration tests
- E2E tests

### Step 3: Set Coverage
- Target percentages
- Critical paths
- Risk-based

### Step 4: Document
- Test plan
- Responsibilities
- Tools

## Quality Criteria

- [ ] Pyramid is balanced
- [ ] Coverage is defined
- [ ] Tools selected

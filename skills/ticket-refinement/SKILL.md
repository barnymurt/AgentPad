# Ticket Refinement (3 Amigos)

PM + Developer + QA collaboration for better tickets. This skill enables effective refinement.

## Core Workflow

### Step 1: Prepare
- Product context
- User stories
- Technical constraints

### Step 2: Discuss (3 Amigos)
- PM: Business value
- Dev: Technical approach
- QA: Testability

### Step 3: Refine
- Acceptance criteria
- Technical notes
- Test scenarios

### Step 4: Document
- Updated ticket
- Dependencies
- Estimates

# Referral Program

Design a referral program that drives organic growth. This skill creates a complete referral strategy.

## Core Workflow

### Step 1: Define Program
- Goals
- Target users
- Value proposition

### Step 2: Design Incentives
- For referrer
- For referred
- Limits

### Step 3: Technical Setup
- Implementation
- Tracking
- Fulfillment

### Step 4: Launch Plan
- Rollout
- Communication
- Optimization

## Output Format

The output follows the structure defined in [references/output-schema.md](references/output-schema.md):

- **Section 1:** Program Design
- **Section 2:** Incentive Structure
- **Section 3:** Technical Plan
- **Section 4:** Launch Plan

## Quality Criteria

- [ ] Incentives are compelling
- [ ] Tracking is in place
- [ ] Fulfillment is defined

## Common Mistakes

1. **No compelling incentive** — Nobody refers.
2. **Friction** — Too hard to refer.
3. **No tracking** — Can't optimize.

# OKR Quality Checklist

Use this checklist to validate your OKRs are valuable and actionable.

---

## Objective Strength Test

### 1. Inspiration Check

- [ ] Does this objective motivate the team?
- [ ] Is it clear why this matters?
- [ ] Would someone outside the team understand it?

### 2. Outcome vs Output Check

- [ ] This describes an outcome, not a feature?
- [ ] It's about user/business value, not shipping?
- [ ] It's not just "launch X"?

### 3. Ownership Check

- [ ] One person/team owns this?
- [ ] They can actually influence the outcome?
- [ ] It's their top priority?

---

## Key Result Strength Test

### 1. Measurability Check

- [ ] There is a specific number target?
- [ ] The measurement is objective?
- [ ] You can calculate progress automatically?

### 2. Ambitious but Achievable Check

- [ ] This is a stretch goal (70% = success)?
- [ ] It's technically possible to achieve?
- [ ] It's not too easy?

### 3. Time-bound Check

- [ ] There is a clear deadline (end of quarter)?
- [ ] Progress can be tracked weekly?
- [ ] The timeline is realistic?

### 4. Outcome-focused Check

- [ ] This measures user behavior, not team activity?
- [ ] It's not "ship 10 features" but "improve X"?
- [ ] Success is meaningful, not just completion?

---

## Common OKR Problems

### Problem 1: Output Objectives

**Bad:** "Launch mobile app"
**Good:** "Deliver a mobile experience that delights users"

### Problem 2: Unmeasurable Key Results

**Bad:** "Improve user experience"
**Good:** "Increase app store rating from 4.0 to 4.5"

### Problem 3: Too Many KRs

**Bad:** 8 key results per objective
**Good:** 3-4 key results per objective

### Problem 4: Not Stretching

**Bad:** "Maintain current conversion rate"
**Good:** "Increase conversion rate by 25%"

### Problem 5: Not Connected to Company Goals

**Bad:** Team OKRs don't align with company OKRs
**Good:** Team OKRs cascade from company OKRs

## Validation Questions

For each Objective:

1. **Would achieving this change our product/business?**
   If no, it's not important enough.

2. **Will the team be proud if we achieve this?**
   If no, it's not inspiring enough.

For each Key Result:

3. **Can we measure progress weekly?**
   If no, it's too vague.

4. **Is 70% achievement still a win?**
   If 100% is easy, it's not ambitious enough.

5. **Does this connect to a company OKR?**
   If no, it might not matter.

# Real-World OKR Examples

## Google OKRs (The Origin)

### Example: Chrome Team

**Objective:** Make the web faster

**Key Results:**
- KR1: Reduce average page load time from 4s to 2s
- KR2: Increase JavaScript performance score from 60 to 90
- KR3: Reduce memory usage by 30%

**Outcome:** Chrome became one of the fastest browsers, driving massive adoption.

## Spotify

### Example: Personalization Team

**Objective:** Make every user feel like the product was made for them

**Key Results:**
- KR1: Increase Discover Weekly engagement by 25%
- KR2: Reach 50% of users using personalized playlists weekly
- KR3: Improve recommendation accuracy (measured by skip rate) by 15%

**Outcome:** Personalization became Spotify's key differentiator.

## LinkedIn

### Example: Mobile Team

**Objective:** Make mobile the primary way to use LinkedIn

**Key Results:**
- KR1: Increase mobile daily active users by 40%
- KR2: Reduce app launch time from 3s to under 1s
- KR3: Get 50% of member interactions from mobile

**Outcome:** Mobile became primary platform, driving engagement.

## Airbnb

### Example: Trust Team

**Key Results:**
- KR1: Increase verified ID completion rate from 60% to 90%
- KR2: Reduce trust-related support tickets by 30%
- KR3: Increase review response rate from hosts to 80%

## Common Patterns

### What Made These OKRs Work

| Pattern | Example |
|---------|---------|
| Outcome-focused | "Increase X" not "Ship X" |
| Clear metrics | Specific percentages |
| Ambitious | 40% improvement |
| Measurable | Hard to argue with |
| Time-bound | Quarterly goals |

---

## OKR Anti-Patterns

### Bad Examples

**Objective:** Launch mobile app
**Problem:** Not measurable, no outcome

**Objective:** Improve performance
**Problem:** No specific target

**Objective:** Do more features
**Problem:** Output not outcome

---

## Lessons Learned

1. **Less is more** - 3-5 KRs per objective
2. **Stretch goals** - 70% achievement is good
3. **Weekly check-ins** - Don't wait until end of quarter
4. **Connect to company** - Align with bigger goals
5. **Focus on outcomes** - Not outputs

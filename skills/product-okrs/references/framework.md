# OKR Framework

## Setting Objectives

### Good Objectives Are

- Qualitative
- Inspirational
- Ambitious but achievable
- Time-bound (quarter)
- Owned by a team/person

### Examples

**Bad:** Launch the mobile app
**Good:** Deliver a mobile experience that delight users

**Bad:** Improve conversion rate
**Good:** Make signup seamless and fast

---

## Setting Key Results

### Good Key Results Are

- Quantitative
- Measurable
- Time-bound
- Outcome-focused (not output)
- 2-5 per objective

### Key Result Format

Current: [X]
Target: [Y]
Measure: [How to measure]

---

## OKR Process

### 1. Planning

- Review company OKRs
- Set team objectives
- Define key results
- Get alignment

### 2. Execution

- Work toward KRs
- Track progress
- Update regularly

### 3. Review

- Score KRs
- Reflect on learnings
- Plan next quarter

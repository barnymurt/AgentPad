# SEO Foundation

Build the SEO foundation that will drive organic traffic to your product. This skill establishes the baseline SEO work needed before and during launch.

## Core Workflow

### Step 1: Understand Search Context

- What do people search for?
- What's the search volume?
- Who's competing?

### Step 2: Keyword Strategy

- Target keywords by stage
- Prioritize by opportunity
- Map keywords to pages

### Step 3: Technical SEO Baseline

- Site structure
- Crawlability
- Page speed
- Mobile-friendliness
- Schema markup

### Step 4: On-Page SEO

- Title tags, meta descriptions
- Header structure
- Content optimization
- Internal linking

### Step 5: Content SEO Plan

- What content to create
- Topics to cover
- Publishing cadence

## Common Mistakes

1. **Keyword stuffing** — Writing for search engines, not users.
2. **Ignoring technical SEO** — Site needs to be crawlable first.
3. **No content plan** — SEO takes time, need consistent content.
4. **Chasing hard keywords** — Start with achievable terms.

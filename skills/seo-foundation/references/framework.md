# SEO Foundation Framework

## Keyword Research

### Types of Keywords
- **Head terms:** High volume, high competition
- **Long-tail:** Lower volume, easier to rank
- **Product:** Direct product searches
- **Informational:** How-to, questions

### Keyword Research Tools
- Google Keyword Planner
- Ahrefs
- SEMrush
- Ubersuggest

## Technical SEO

### Core Elements
- Site speed
- Mobile-friendliness
- Crawlability
- Site architecture
- SSL/HTTPS

### Technical Audit
- XML sitemap
- Robots.txt
- Schema markup
- Canonical URLs
- 404 pages

## On-Page SEO

### Elements
- Title tags
- Meta descriptions
- Header hierarchy
- URL structure
- Image alt text

### Best Practices
- One H1 per page
- Keywords in title, first 100 words
- Natural keyword usage
- Internal linking

## Content SEO

### Content Strategy
- Topic clusters
- Pillar pages
- Regular updates

### SEO Content Types
- How-to guides
- Industry articles
- Product comparisons
- FAQs

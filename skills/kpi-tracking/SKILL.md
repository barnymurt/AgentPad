# KPI Tracking

Define, track, and report on key performance indicators. Understand what metrics matter and how to measure progress.

## When to Use This Skill

Use when:
- Defining KPIs for the first time
- Setting targets for metrics
- Tracking progress
- Reporting to stakeholders
- Reviewing KPI performance

## KPI Framework

### What Makes a Good KPI

| Criterion | Description |
|----------|-------------|
| Actionable | You can do something about it |
| Measurable | Can be quantified |
| Relevant | Aligns with business goals |
| Time-bound | Has a timeframe |

### KPI Categories

| Category | Examples |
|----------|----------|
| Acquisition | Visitors, sign-ups, CAC |
| Activation | Activation rate, time to value |
| Retention | Churn, retention, DAU/MAU |
| Revenue | MRR, ARPU, LTV |
| Engagement | Sessions, duration, features used |

**TARGETS**

- Target
- Progress percentage
- Trend

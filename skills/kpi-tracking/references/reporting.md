# KPI Reporting Guide

## Reporting Frequency

| Frequency | When | Audience |
|-----------|------|----------|
| Daily | Critical metrics | Operations |
| Weekly | All KPIs | Team |
| Monthly | Detailed report | Leadership |
| Quarterly | Full review | All stakeholders |

---

## Report Structure

### 1. Executive Summary

- Overall KPI health
- Key wins
- Key concerns

### 2. KPI Performance

- Each KPI vs target
- Progress percentage
- Trend

### 3. Analysis

- Why metrics moved
- What actions taken
- What's planned

### 4. Next Steps

- Focus areas
- Actions required

---

## Communication Tips

1. **Be concise** - Lead with key points
2. **Show trends** - Not just current state
3. **Be actionable** - Connect to decisions
4. **Be visual** - Charts over tables
5. **Be consistent** - Same format each time

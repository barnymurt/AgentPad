# Automation Framework

Build test automation framework. This skill implements your testing infrastructure.

## Core Workflow

### Step 1: Choose Tools
- E2E: Playwright, Cypress
- Integration: Supertest
- Reporting

### Step 2: Structure Tests
- Page object model
- Fixtures
- Helpers

### Step 3: Implement
- Write tests
- Set up fixtures
- Add assertions

### Step 4: Integrate CI
- Pipeline setup
- Reporting
- Notifications

## Quality Criteria

- [ ] Tests are maintainable
- [ ] CI integrated
- [ ] Reports clear

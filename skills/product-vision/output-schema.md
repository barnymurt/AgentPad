# Product Vision Output Schema

This defines the structure of product vision output.

## Output Structure

```
PRODUCT VISION

[Vision statement - 1-2 sentences describing the future you're creating]

MISSION STATEMENT

[Mission - why you exist, 1-2 sentences]

POSITIONING STATEMENT

For [target customer] who [need/problem], [product name] is [category] that [key benefit]. Unlike [competitor alternative], our product [key differentiator].

CORE VALUES

Value 1: [Name]
Description: [What this value means in practice]

Value 2: [Name]
Description: ...

Value 3: [Name]
Description: ...

STRATEGIC PILLARS

Pillar 1: [Name]
Description: [What this pillar covers]

Pillar 2: [Name]
Description: ...

Pillar 3: [Name]
Description: ...

SUCCESS INDICATORS

6-Month Milestone
[What success looks like at 6 months]

12-Month Milestone
[What success looks like at 12 months]

24-Month Milestone
[What success looks like at 24 months]

VISION QUALITY SCORE

Use the checklist in references/quality-checklist.md to score:

Clarity: [1-5]
Inspiration: [1-5]
Differentiation: [1-5]
Feasibility: [1-5]
Focus: [1-5]
Customer Focus: [1-5]

Total: [X/30]

If below 20, consider refining.
```

## Quality Guidelines

Vision should be:
- Written in plain language
- No jargon or buzzwords
- Customer-focused
- Specific enough to guide decisions

Avoid:
- Corporate buzzwords
- Abstract concepts without specifics
- Features or technical details
- Anything that could apply to any company

# Pricing Launch

Finalize pricing strategy and configure for launch. This skill ensures pricing is ready for go-live.

## Core Workflow

### Step 1: Finalize Strategy
- Pricing model confirmation
- Tier structure
- Discount strategy

### Step 2: Configure Pricing
- Set prices
- Create tiers
- Set limits

### Step 3: Launch Offers
- Launch discount
- Terms
- Duration

### Step 4: Documentation
- Pricing page content
- FAQ
- Sales training

## Output Format

The output follows the structure defined in [references/output-schema.md](references/output-schema.md):

- **Section 1:** Pricing Strategy
- **Section 2:** Tier Configuration
- **Section 3:** Launch Offers
- **Section 4:** Documentation

## Quality Criteria

- [ ] Pricing matches value
- [ ] Tiers are clear
- [ ] Launch offer is defined

## Common Mistakes

1. **Too complex** — Confusing pricing loses customers.
2. **No launch offer** — Leaving money on the table.
3. **Underpricing** — Undervaluing product.

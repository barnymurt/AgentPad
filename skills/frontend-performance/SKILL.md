# Frontend Performance

Optimize frontend for speed. This skill improves Core Web Vitals.

## Core Workflow

### Step 1: Measure
- Lighthouse
- Core Web Vitals
- Real user metrics

### Step 2: Optimize
- Bundle size
- Images
- Code splitting

### Step 3: Improve Loading
- SSR/SSG
- Prefetching
- Caching

### Step 4: Monitor
- RUM
- Alerts
- Trends

## Output Format

- Performance audit
- Optimization plan
- Monitoring setup

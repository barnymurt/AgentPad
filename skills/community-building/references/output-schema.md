# Community Building Output Schema

## Consumes
- context.product - Product context
- context.target_audience - Target users

## Produces
- context.community_strategy - Strategy document

## Output Structure

### Section 1: Goals & Vision (required)
- purpose: string - Why community exists
- value_proposition: string - Member value

### Section 2: Platform Strategy (required)
- platform: string - Selected platform
- features: array - Key features needed

### Section 3: Engagement Plan (required)
- content: array - Community content
- events: array - Community events
- moderation: string - Moderation approach

### Section 4: Growth Strategy (required)
- invite_strategy: string - How to grow
- ambassador: object - Ambassador program

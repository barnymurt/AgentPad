# Product Health Check

Regular assessment of product health across multiple dimensions. Identify what's working, what's not, and what needs attention.

## When to Use This Skill

Use when:
- Regular assessment (monthly or quarterly)
- After major releases
- When metrics seem off
- Preparing for investor updates
- Making strategic decisions

## Health Check Frequency

| Product Stage | Recommended Frequency |
|--------------|---------------------|
| Pre-launch | Not applicable - use validation instead |
| MVP/Early (0-100 users) | Monthly |
| Growth (100-1000 users) | Monthly |
| Scaling (1000-10000+) | Monthly |
| Mature | Quarterly |

## Workflow

### Step 1: Gather Data

Collect information across all health dimensions:

**User Engagement**
- Active users and trends
- Feature usage patterns
- User feedback

**Product-Market Fit**
- Retention curves
- User satisfaction signals
- Referral rates

**Technical Health**
- Performance metrics
- Error rates
- Reliability

**Business Health**
- Revenue metrics
- Customer health
- Growth rates

**Competitive Position**
- Market changes
- Competitor moves
- Differentiation

### Step 2: Assess Each Dimension

Rate each dimension:
- Green: Healthy, no action needed
- Yellow: Watch, may need attention
- Red: Critical, requires action

### Step 3: Identify Risks

Document risks with:
- What could go wrong
- Likelihood
- Impact if it happens

### Step 4: Recommend Actions

For each issue, recommend specific actions.

## Output Format

The skill produces these sections:

**HEALTH CHECK SUMMARY**

Overall status: Green/Yellow/Red
Date of assessment
Key findings (3-5 sentences)

**DIMENSION ASSESSMENTS**

For each dimension:
- Status (Green/Yellow/Red)
- What's working
- What's not working
- Data sources used

**RISKS IDENTIFIED**

Risk: Description
Likelihood: High/Medium/Low
Impact: High/Medium/Low
Mitigation: What to do

**RECOMMENDED ACTIONS**

Priority 1: Action description
Priority 2: ...

**WARNING SIGNS TO WATCH**

Red flags that would indicate declining health

**BENCHMARKS**

How your metrics compare to industry standards

# Product Health Check Framework

## Five Health Dimensions

### 1. User Engagement

Are users actively using your product?

**Green indicators:**
- Growing active user base
- Users are using core features
- Engagement is consistent or growing

**Yellow indicators:**
- Flat engagement
- Users only using one feature
- Declining session time

**Red indicators:**
- Declining active users
- Users churning quickly
- No engagement with core features

---

### 2. Product-Market Fit

Are you solving a real problem for the right users?

**Green indicators:**
- Users recommend you to others (NPS 50+)
- Users are disappointed when you have outages
- Strong retention curves
- Users find your product within days

**Yellow indicators:**
- Moderate NPS (30-50)
- Some user segments are happy, others not
- Retention is okay but not great
- Some users don't return

**Red indicators:**
- Low NPS (below 30)
- Users don't recommend
- Poor retention
- Users don't understand value quickly

---

### 3. Technical Health

Is your product performing well?

**Green indicators:**
- Fast load times (under 2 seconds)
- Low error rates (under 1%)
- High uptime (99.9%+)
- Few support tickets about bugs

**Yellow indicators:**
- Some performance issues
- Occasional errors
- Minor downtime
- Some support tickets about functionality

**Red indicators:**
- Slow performance
- Frequent errors
- Downtime
- Many support tickets about bugs

---

### 4. Business Health

Is your business model working?

**Green indicators:**
- Growing revenue
- Good unit economics (LTV:CAC 3:1+)
- Healthy margins
- Acquisition costs are reasonable

**Yellow indicators:**
- Flat revenue
- Unit economics are borderline
- Some margin pressure
- Acquisition costs increasing

**Red indicators:**
- Declining revenue
- Poor unit economics
- Negative margins
- Acquisition costs too high

---

### 5. Competitive Position

How do you compare to alternatives?

**Green indicators:**
- Clear differentiation
- Growing market share
- Customers choose you over competitors
- Features ahead in key areas

**Yellow indicators:**
- Some differentiation
- Stable market share
- Competitive on some dimensions
- Feature parity in most areas

**Red indicators:**
- No clear differentiation
- Losing market share
- Customers prefer competitors
- Behind on key features

---

## Assessment Process

### Step 1: Collect Data

For each dimension, gather:
- Quantitative data (metrics)
- Qualitative data (feedback)
- Comparative data (benchmarks)

### Step 2: Rate Each Dimension

Use Green/Yellow/Red:
- Green: Healthy, continue current approach
- Yellow: Monitor, consider improvements
- Red: Take action immediately

### Step 3: Identify Patterns

Are multiple dimensions showing similar trends?
- If all Green: Maintain, but stay vigilant
- If multiple Red: Critical attention needed
- If mixed: Prioritize based on impact

### Step 4: Recommend Actions

For each Yellow or Red:
- Specific action to take
- Timeline for improvement
- How to measure success

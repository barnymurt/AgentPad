# TDD

Implement test-driven development. This skill enables quality-first development.

## Core Workflow

### Step 1: Write Failing Test
- Red: Write test first
- Define expected behavior

### Step 2: Make Pass
- Green: Write minimal code
- Get test to pass

### Step 3: Refactor
- Blue: Improve code
- Keep tests passing

### Step 4: Repeat
- Continue cycle
- Build test coverage

## Quality Criteria

- [ ] Tests drive code
- [ ] High coverage
- [ ] Refactored

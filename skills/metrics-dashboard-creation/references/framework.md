# Dashboard Design Framework

## Dashboard Types

### 1. Executive Dashboard

**Purpose:** High-level business health

**Audience:** Founders, executives, investors

**Metrics:**
- Revenue
- User growth
- Key KPIs
- Goals vs actual

**Refresh:** Daily

---

### 2. Product Dashboard

**Purpose:** Product performance

**Audience:** Product managers, designers

**Metrics:**
- Active users
- Feature usage
- Engagement
- Retention

**Refresh:** Real-time to daily

---

### 3. Operations Dashboard

**Purpose:** System health

**Audience:** Engineering, ops

**Metrics:**
- Uptime
- Error rates
- Response times
- Infrastructure

**Refresh:** Real-time

---

### 4. Marketing Dashboard

**Purpose:** Marketing performance

**Audience:** Marketing, growth

**Metrics:**
- Traffic
- Conversion
- Campaign performance
- Cost per acquisition

**Refresh:** Daily

---

## Dashboard Layout Principles

### Top Section: Key Metrics

Most important numbers, trends

### Middle Section: Supporting Metrics

Details that explain top metrics

### Bottom Section: Context

Trends, comparisons, benchmarks

---

## Visualization Types

| Metric Type | Best Visualization |
|------------|-------------------|
| Single number | Big number, gauge |
| Trend over time | Line chart |
| Comparison | Bar chart |
| Parts of whole | Pie chart, treemap |
| Distribution | Histogram |
| Correlation | Scatter plot |

---

## Common Mistakes

1. **Too many metrics** - Focus on 5-10 key ones
2. **Vanity metrics** - Show actionable data
3. **No benchmarks** - Compare to goals/competitors
4. **No alerts** - Know when things go wrong
5. **Not updating** - Keep dashboards relevant

## Dashboard Best Practices

1. **Lead with key numbers** - Most important first
2. **Show trends** - Not just current state
3. **Add context** - Goals, benchmarks, comparisons
4. **Use colors appropriately** - Green/yellow/red with purpose
5. **Keep it simple** - Don't overwhelm
6. **Update regularly** - Outdated dashboards are useless

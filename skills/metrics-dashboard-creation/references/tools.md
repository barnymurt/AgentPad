## Choosing a Tool

### Questions to Ask

1. **What's your budget?**
2. **How technical is your team?**
3. **What data do you need?**
4. **Who uses the dashboard?**
5. **How fast do you need to set up?**

### Recommendations

**No budget, simple:**
- Google Data Studio + analytics tools

**Small budget, product focus:**
- PostHog or Amplitude free tier

**Growing product:**
- Amplitude or Mixpanel

**Enterprise:**
- Looker or custom

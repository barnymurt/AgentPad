# Metrics Dashboard Creation

Create operational dashboards to track and visualize your key metrics. Understand what to display and how to set it up.

## When to Use This Skill

Use when:
- Setting up analytics for the first time
- Creating a new dashboard
- Improving existing dashboards
- Deciding what metrics to show
- Choosing dashboard tools

## Dashboard Tools by Stage

| Stage | Recommended Tools | Cost |
|-------|------------------|------|
| Pre-launch | Spreadsheet, Google Data Studio | Free |
| MVP | Mixpanel Free, Amplitude Free, PostHog | Free tier |
| Growth | Amplitude, Mixpanel | $100-500/mo |
| Scale | Mixpanel, Amplitude, custom | $500+/mo |

## Output Format

The skill produces these sections:

**DASHBOARD OVERVIEW**

Purpose: Why this dashboard exists
Audience: Who uses it
Refresh: How often updated

**DATA SOURCES**

For each source:
- Name
- What data available
- How to connect

**METRICS**

For each metric:
- Name
- Calculation
- Visualization type
- Benchmark

**DASHBOARD SECTIONS**

Section: Name
Metrics included
Layout recommendation

**ALERTS**

Alert: Condition
Notification method
Threshold

**IMPLEMENTATION**

Tool recommendation
Setup steps
Tips

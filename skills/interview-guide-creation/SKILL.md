# Interview Guide Creation

Create structured interview scripts for effective customer discovery and user research. Unlike generic question lists, this skill produces research-quality interview guides with properly sequenced questions, participant screening criteria, interviewer facilitation tips, and follow-up probes to extract deep insights.

**Note**: This skill requires clear research objectives. See Step 1.

## Core Workflow

### Step 1: Define Research Objectives

**Before writing questions, establish:**

1. **Research purpose:**
   - Discovery: Learn about user problems
   - Validation: Test assumptions
   - Feedback: Gather input on solution
   - Evaluation: Assess usability or preference

2. **What you need to learn:**
   - Specific questions to answer
   - Key decisions to inform
   - Assumptions to validate

3. **Target participant type:**
   - Current customers
   - Potential customers
   - Users of competitor products
   - Domain experts

**If objectives unclear:**
- Ask user to define goals before proceeding
- Don't create generic interview without purpose

### Step 2: Define Participant Criteria

**Screener Questions:**

Recruit the right participants:

| Criteria | Question | Screening |
|----------|----------|----------|
| Role | What is your role? | Must be target role |
| Experience | How long using [product type]? | Minimum experience |
| Frequency | How often do you [action]? | Must match frequency |
| Company size | How large is your company? | Must match segment |

**Recruitment sources:**
- Customer lists
- LinkedIn outreach
- Professional networks
- Recruitment platforms
- Cold outreach

**Target number:**
- Discovery: 5-10 participants
- Validation: 5-8 participants
- Feedback: 3-5 participants

### Step 3: Write Screener Questions

**Purpose:** Qualify participants, ensure right fit

**Format:**
- Yes/No questions
- Quick to answer
- Clear pass/fail criteria

**Example screener:**
```
1. Do you currently use project management software? (Yes → continue)
2. How many people on your team? (5+ → continue)
3. Are you involved in choosing software for your team? (Yes → continue)
4. What's your email for follow-up?
```

### Step 4: Structure Interview Questions

**Sequencing:**

1. **Opening (2-3 min)**
   - Welcome, purpose
   - Establish rapport
   - Set expectations

2. **Warm-up (5 min)**
   - Easy, non-threatening questions
   - Build comfort
   - Learn context

3. **Core (20-30 min)**
   - Main research questions
   - Open-ended
   - Follow-up probes

4. **Deep-dive (10 min)**
   - Most important topics
   - Detailed exploration
   - Specific examples

5. **Wrap-up (5 min)**
   - Summary
   - Any final thoughts
   - Thank you, next steps

**Total time:** 45-60 minutes

### Step 5: Write Main Questions

**Question Types:**

| Type | Purpose | Example |
|------|---------|---------|
| **Open-ended** | Explore | "Tell me about..." |
| **Specific** | Detail | "What does that look like?" |
| **Comparative** | Context | "How is this different from...?" |
| **Hypothetical** | Future | "If you could..." |
| **Behavioral** | Past | "Tell me about a time..." |

**Question guidelines:**
- Start with "Tell me about..." or "Describe..."
- Avoid yes/no questions in main section
- One question at a time
- No leading questions

### Step 6: Add Follow-up Probes

**Probe types:**

| Probe | Purpose | Example |
|-------|---------|---------|
| **Silence** | Wait, let them think | [Wait 5 seconds] |
| **Tell me more** | Go deeper | "Can you tell me more about that?" |
| **Specific** | Get details | "What did that look like?" |
| **Example** | Concrete instance | "Can you give me an example?" |
| **Why** | Understand reason | "Why is that important?" |
| **How** | Process | "How do you do that today?" |
| **Feel** | Emotions | "How did that make you feel?" |

**Probe strategy:**
- Don't rush through silences
- Follow interesting answers, not just script
- Use probes to get specific examples

### Step 7: Add Interviewer Tips

**Facilitation guidance:**

1. **Building rapport:**
   - Be friendly, conversational
   - Share briefly about yourself
   - Show genuine interest

2. **Probing techniques:**
   - Listen actively
   - Don't interrupt
   - Use silence
   - Reflect back ("So what I'm hearing is...")

3. **Staying on track:**
   - Keep time per section
   - Note interesting tangents for follow-up
   - Don't force answers

4. **Recording:**
   - Ask permission to record
   - Take notes anyway
   - Note non-verbal cues

### Step 8: Pilot Test Guide

**Before full recruitment:**

1. **Test with 1-2 participants:**
   - Friends, colleagues in target role
   - Practice running interview
   - Time yourself

2. **Refine based on pilot:**
   - Questions that don't land
   - Time issues
   - Flow problems

3. **Adjust:**
   - Remove confusing questions
   - Add missing probes
   - Adjust sequencing

## Output Format

The output follows the structure defined in [references/output-schema.md](references/output-schema.md):

- **Research Objectives** — Purpose and goals
- **Participant Criteria** — Screener questions and recruitment
- **Interview Structure** — Sections and timing
- **Main Questions** — Open-ended, sequenced
- **Follow-up Probes** — Techniques and examples
- **Interviewer Tips** — Facilitation guidance
- **Pilot Plan** — Testing recommendations

Expected length: 1,500-2,500 words

## Quality Criteria

- [ ] Research objectives clearly defined
- [ ] Participant criteria with screener questions
- [ ] Recruitment guidance included
- [ ] Interview structured with time allocation
- [ ] Minimum 10 substantive questions
- [ ] Questions open-ended (not yes/no)
- [ ] Follow-up probes included
- [ ] Interviewer facilitation tips provided
- [ ] Pilot test recommended
- [ ] Questions sequenced logically (warm-up → core → deep-dive → wrap-up)

## Common Mistakes

1. **Writing yes/no questions:** Main questions should be open-ended. Save yes/no for screening only.

2. **No warm-up:** Jumping straight to hard questions. Always warm up to build rapport.

3. **Leading questions:** "Don't you think X is better?" biases responses. Ask neutrally.

4. **No follow-up probes:** Sticking to script exactly. Missing rich insights.

5. **Too many questions:** 45-minute interview = 10-12 questions max. Quality over quantity.

6. **No pilot testing:** Running interviews without practicing. First sessions are always rough.

7. **Skipping screener:** Not qualifying participants. Wasting time with wrong people.

8. **Not recording:** Trusting memory. Always record (with permission) and take notes.

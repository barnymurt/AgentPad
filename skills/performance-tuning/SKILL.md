# Performance Tuning

Optimize database performance for speed and scale. This skill identifies and fixes performance bottlenecks.

## Core Workflow

### Step 1: Identify Bottlenecks
- Slow queries
- Missing indexes
- Resource constraints

### Step 2: Analyze Queries
- Execution plans
- Query structure
- Index usage

### Step 3: Optimize
- Add indexes
- Rewrite queries
- Add caching

### Step 4: Verify
- Measure improvement
- Monitor in production

## Output Format

- Performance analysis
- Optimization recommendations
- Implementation plan

## Quality Criteria

- [ ] Bottlenecks identified
- [ ] Optimizations effective
- [ ] Measured improvement

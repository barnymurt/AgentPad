# Devil's Advocate (GTM) Worked Example

## Assumptions Challenged

### Pricing
- "Price is right" → What if too high?
- "Launch discount enough" → What if need more?

### Channels
- "Twitter will work" → What if algorithm changes?
- "Content drives growth" → What if takes longer?

### Launch
- "Launch week sufficient" → What if need more time?
- "Team can handle" → What if overwhelmed?

## Blind Spots
- Competitor discount response
- Support capacity
- Beta user churn risk

## Recommendations
1. Prepare competitor response
2. Add support buffer
3. Extend soft launch

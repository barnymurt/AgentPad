# Messaging Framework Worked Example

## Context

**Product:** TaskFlow — Project management tool for creative agencies
**Target:** Creative agencies (design studios, video production, marketing teams) with 5-50 employees
**Stage:** Pre-launch

---

## Step 1: Product and Market Context

### Product Definition
- **Name:** TaskFlow
- **Category:** Project management SaaS
- **Core function:** All-in-one project management for creative teams with time tracking, client portals, and invoicing
- **Key benefit:** Save 10+ hours per week on administrative work
- **Differentiator:** Built specifically for creative workflows (design files, feedback, approvals) with built-in time tracking and invoicing

### Target Audience
- **Primary:** Studio heads and project managers at creative agencies (5-50 employees)
- **Secondary:** Freelance creative directors managing multiple clients
- **Not for:** Software teams, large enterprises, non-creative businesses

### Competitive Context
- **Competitors:** Asana, Monday.com, Trello, ClickUp, Frame.io
- **Our differentiation:** Creative-specific features (design file previews, client feedback tools, time tracking + invoicing)
- **Their weakness:** Generic project management, no creative focus, no invoicing

---

## Step 2: Value Proposition

### Jobs-to-be-Done

**Functional:**
- Track time on client projects accurately
- Get client feedback on deliverables in one place
- Generate invoices from tracked time automatically
- Keep projects on scope and on budget

**Emotional:**
- Feel in control of projects
- Look professional to clients
- Reduce stress from administrative burden
- Spend more time on creative work

**Social:**
- Be seen as organized and professional
- Impress clients with seamless experience
- Build reputation for reliable delivery

### Value Proposition Statement

**"TaskFlow helps creative agencies save 10+ hours per week on project management by combining task tracking, client feedback, and invoicing in one tool — so teams can focus on creative work instead of admin."**

## Step 4: Key Messages

### Elevator Pitch (25 words)
"TaskFlow is project management built for creative teams — track time, get client feedback, and invoice clients in one tool."

### Short Description (2 minutes)
"TaskFlow helps creative agencies manage projects more efficiently. Unlike generic project tools, it's built specifically for creative workflows — with design file previews, client feedback tools, time tracking, and automatic invoicing. Customers typically save 10+ hours per week on administrative work and improve client satisfaction."

### Long Description
"TaskFlow is the all-in-one project management platform designed specifically for creative agencies and studios. It combines task management, time tracking, client feedback, and invoicing in one seamless tool — eliminating the need for multiple fragmented solutions.

Key features include:
- **Task management** with design file previews
- **Client feedback** in one thread
- **Time tracking** with detailed reports
- **Automatic invoicing** from tracked time
- **Client portals** for seamless communication

Creative teams use TaskFlow to reduce administrative burden, improve client communication, and focus on what they do best — creative work."

### Audience-Specific Messages

**For Agency Owners (Primary):**
"TaskFlow gives you visibility into every project, helps you bill accurately for all time, and keeps clients happy with professional communication — so you can scale your agency without adding overhead."

**For Project Managers:**
"TaskFlow makes it easy to manage multiple projects, track time as you go, and keep clients updated — all without chasing people for status or digging through Slack for feedback."

**For Developers/Technical:**
"TaskFlow integrates with the tools you use (Figma, Slack, Stripe), offers a robust API, and provides the data export capabilities enterprises need."

## Step 7: Objection Handling

| Objection | Category | Response |
|-----------|----------|----------|
| "We use Asana/Monday" | Alternative | "Great tools! But they weren't built for creative work. TaskFlow has design previews, client feedback, time tracking, and invoicing — you'd need 3+ tools to match what TaskFlow does in one." |

## Summary

This messaging framework positions TaskFlow as the only project management tool built specifically for creative agencies. The core message — "save 10+ hours per week" — is specific and measurable. Differentiation — creative-specific features with time tracking and invoicing — is clear and hard for competitors to match quickly.

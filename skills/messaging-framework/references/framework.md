# Messaging Framework Methodology

## Overview

Messaging framework development is the process of creating coherent, consistent messages that communicate your product's value across all channels and audiences. This framework provides the methodology for building effective messaging.

---

## Value Proposition Development

### Jobs-to-be-Done (JTBD)

**Three dimensions:**

| Type | Description | Example |
|------|-------------|---------|
| Functional | The practical job | Send invoices quickly |
| Emotional | How they want to feel | Professional, in control |
| Social | How they want to be seen | Smart, successful |

**Formulating JTBD:**
"For [target customer] who [has problem/job], I want to [action] so that [desired outcome]"

### Value Proposition Templates

**Template A (Problem-focused):**
For [target customer] who struggles with [problem], [product name] is a [category] that [solves the problem] by [how it works]. Unlike [competitor], we [key differentiation].

**Template B (Outcome-focused):**
[Product name] helps [target customer] achieve [desired outcome] [quantified]. Unlike [competitor], we [key differentiation].

**Template C (Category-maker):**
[Product name] is the first [category] that [describes the new approach]. For [target customer], this means [benefit].

## Positioning Statement

### Components

| Component | Question | Example |
|-----------|----------|---------|
| Target | Who is this for? | Small business owners |
| Problem | What problem? | Managing finances is time-consuming |
| Category | What type of product? | Financial management platform |
| Benefit | What's the key benefit? | Save 5 hours per week |
| Differentiation | Why different? | AI-powered automation |

### Positioning Formula

"For [target] who [problem], [product] is a [category] that [benefit]. Unlike [competitor], [differentiation]."

### Differentiation Types

| Type | Description | Example |
|------|-------------|---------|
| Feature | Unique capability | Only product with X |
| Performance | Better at something | Faster, more accurate |
| Price | Lower cost | 50% less expensive |
| Service | Better support | 24/7 dedicated support |
| Experience | Better journey | Easier to use |
| Scope | Broader/narrower | Only solution for X |

## Key Messages Development

### Elevator Pitch (30 seconds)

**Formula:**
"[Product] helps [target] [solve problem] so they can [benefit]. Unlike [competitor], we [differentiation]."

**Example:**
"InvoiceFlow helps freelance designers get paid faster by automating invoicing and follow-ups. Unlike QuickBooks, it's designed specifically for creative professionals."

### Audience Segmentation

**Common audiences:**

| Audience | Primary Concern | Message Focus |
|----------|-----------------|---------------|
| Developers | Technical fit, API | Integration, security |
| Executives | ROI, strategy | Revenue, efficiency |
| End users | Ease, personal benefit | Time saved, simpler |
| Procurement | Price, terms | Value, compliance |

### Message Adaptation

**By audience interest:**

- Technical audience → Details, specs, integrations
- Business audience → ROI, outcomes, strategy
- End user → Simplicity, personal benefit

## Proof Points

### Types of Evidence

| Type | Example |
|------|---------|
| Customer quote | "We saved 10 hours/week" |
| Case study | Company X achieved Y |
| Data point | 95% customer satisfaction |
| Award | G2 category leader |
| Integration | Works with X tools |
| Certification | SOC 2 compliant |

### Source Credibility

- **High credibility:** Independent research, verified customers
- **Medium credibility:** Industry reports, analyst mentions
- **Lower credibility:** Internal data, testimonials

## Channel Adaptation

### Channel Considerations

| Channel | Length | Style | Goal |
|---------|--------|-------|------|
| Website hero | 10 words | Punchy | Grab attention |
| Product page | 100 words | Descriptive | Convince |
| Sales email | 200 words | Personal | Connect |
| Press release | 500 words | Newsworthy | Earned coverage |
| Social | Varies | Engaging | Interaction |

### Adaptation Principles

1. **Lead with what matters to that audience**
2. **Keep core message consistent**
3. **Adapt length and tone**
4. **Include channel-appropriate CTAs**

## Objection Handling

### Common Objections

| Category | Examples |
|----------|----------|
| Price | "Too expensive", "Can't afford" |
| Trust | "Never heard of you", "New company" |
| Need | "Don't need this", "Current solution works" |
| Timing | "Not now", "Too busy" |
| Alternative | "Using competitor", "Built in-house" |

### Response Framework

1. **Acknowledge** — Validate the concern
2. **Reframe** — Offer new perspective
3. **Evidence** — Provide proof
4. **Guide** — Next step

---

## Quality Checklist

- [ ] Value proposition is specific and measurable
- [ ] Positioning statement includes all components
- [ ] Differentiation is believable and unique
- [ ] Messages tailored to at least 2 audiences
- [ ] Proof points are credible
- [ ] Messages consistent across channels
- [ ] Objection responses prepared
- [ ] Tested with real customers

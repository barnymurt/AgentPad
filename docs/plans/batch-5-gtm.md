## 1. Overview

### 1.1 What Batch 5 Enables

Batch 5 provides **go-to-market capabilities** — the skills needed to launch a product and plan for initial growth. It sits in the product lifecycle after Technical Readiness:

```
Validation Pack (Batch 1) → Technical Readiness (Batch 1) → Research & Design (Batches 2-4) → GTM (Batch 5) → Growth
```

### 1.2 Key Philosophy: Under the Hood, Phased Scaling

GTM skills are **"under the hood"** — agents discover and enable additional capabilities as needed based on product scope:

```
User: "I want to launch my product"
Agent: "You have X GTM capabilities available. Based on your product scope,
        here are the recommended skills. As you scale, more become relevant."
```

**Product development is a cycle, not a linear pipeline:**

```
┌─────────────────────────────────────────────────────────┐
│                    PRODUCT CYCLE                        │
│                                                          │
│   ┌─────────┐    ┌─────────┐    ┌─────────┐          │
│   │Research │───▶│  Build  │───▶│  Launch │          │
│   └─────────┘    └─────────┘    └─────────┘          │
│        ▲                              │                │
│        └──────────────────────────────┘                │
│                    (iterate)                             │
└─────────────────────────────────────────────────────────┘
```

GTM isn't a one-time event — it enables iteration: Launch → Measure → Learn → Iterate → Launch v2

### 1.3 The GTM Pack

Like Validation Pack, Batch 5 offers a **GTM Pack** — a chained skillset producing a deliverable:

**GTM Pack answers:** "How do I launch this product and plan for initial growth?"

## 2. Phased Skill Approach

### 2.1 Why Phased?

- **User clarity**: Skills are enabled based on product scope
- **Agent discovery**: Agents recommend appropriate phase
- **Scalability**: Users can scale up GTM as needed
- **Testing**: Core skills testable in MVP

### 2.2 Phase Levels

| Phase | Skills | GTM Pack Steps | When to Enable |
|-------|--------|---------------|----------------|
| **Minimal** | 2 | 2 | Always available |
| **Recommended** | 6 | 4 | For any serious launch |
| **Extended** | 10 | 5 | When channels matter |
| **Full** | 14 | 6 | For enterprise/b2b |

### 2.3 Phase Discovery

The agent evaluates:
- Product scope (B2B vs B2C, SMB vs Enterprise)
- Target market size
- Revenue model
- Competitive context

Then recommends: "Based on your scope, here's the GTM Pack at phase X"

## 4. The GTM Pack

### 4.1 Pack Overview

**GTM Pack** is an orchestrated skill chain producing a comprehensive launch plan.

**Question answered:** "How do I launch this product successfully?"

### 4.2 Minimal Pack (2 steps)

For quick, basic launches:

```
Step 1: messaging-framework
Step 2: launch-planning
    ↓
Synthesis → Minimal GTM Pack
```

### 4.3 Recommended Pack (4 steps)

For serious launches:

```
Step 1: messaging-framework
Step 2: channel-strategy
Step 3: content-strategy
Step 4: launch-planning
    ↓
Synthesis → Recommended GTM Pack
```

### 4.4 Extended Pack (5 steps)

For channel-focused launches:

```
Step 1: messaging-framework
Step 2: channel-strategy
Step 3: content-strategy
Step 4: seo-foundation
Step 5: launch-planning
    ↓
Synthesis → Extended GTM Pack
```

### 4.5 Full Pack (6 steps)

For comprehensive launches:

```
Step 1: messaging-framework
Step 2: channel-strategy
Step 3: content-strategy
Step 4: launch-analytics
Step 5: seo-foundation
Step 6: launch-planning
    ↓
Synthesis → Full GTM Pack
```

### 4.6 Deliverable Sections

All pack variants include:

1. **Launch Overview** — Timeline, milestones, go/no-go criteria
2. **Messaging Framework** — Value prop, positioning, key messages
3. **Channel Plan** — Prioritized acquisition channels with rationale
4. **Content Calendar** — Launch content mapped to channels
5. **Risk Register** — Launch risks with mitigations

Extended/Full variants add:
6. **Analytics Dashboard** — KPIs, tracking, targets
7. **Post-Launch Plan** — First 30/60/90 days

## 5. Agent Discovery Protocol

### 5.1 How Agents Select Phase

```
Agent receives: User wants to launch product
    ↓
Agent evaluates:
    - Product type (B2B/B2C/SMB/Enterprise)
    - Market scope (local/global)
    - Revenue model (subscription/one-time)
    - Competitive context
    ↓
Agent recommends:
    - "Based on your scope, use GTM Pack at Phase X"
    - "Here are the skills that apply to your situation"
    - "As you scale, these additional skills become relevant"
```

### 5.2 Phase Triggers

| Trigger | Enable Phase |
|---------|-------------|
| Any product launch | Minimal (2 skills) |
| Serious market entry | Recommended (6 skills) |
| Channel-dependent growth | Extended (10 skills) |
| Enterprise/b2b focus | Full (14 skills) |

## 8. Quality Gates

### Gate 1: Messaging Validation

**Before:** Proceeding with channel strategy

**Criteria:**
- Value proposition tested (not just assumed)
- Positioning resonates with target audience
- Key messages differentiated

### Gate 2: Channel Readiness

**Before:** Launch

**Criteria:**
- At least 2 channels with proven setup
- Tracking in place
- Content ready for top channel

### Gate 3: Launch Readiness

**Before:** Go live

**Criteria:**
- All critical paths tested
- Support documentation ready
- Rollback plan in place
